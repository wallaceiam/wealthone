# WealthOne Event Sourcing Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans. This plan supersedes mutable-model persistence instructions in the earlier data, iOS, and Watch plans; those plans continue to define feature parity and legacy formats.

**Goal:** Deliver native iOS 17+ WealthOne with permanent replayable saved-edit history, deterministic eventual convergence, migration and full JSON recovery, and a focused Watch companion.

**Architecture:** A Foundation-only Swift package owns versioned immutable events, validation, deterministic projections and archive compatibility. A local durable event repository syncs immutable events through private CloudKit; projections remain device-local. The command path saves before publishing success. SwiftUI and Watch query projections and issue commands.

**Tech Stack:** Swift 6, SwiftUI, Foundation, CloudKit, SwiftData/local persistence, WatchConnectivity, Swift Charts; iOS 17+, watchOS 10+.

**Spec:** ../specs/2026-10-28-wealthone-native-ios-design.md

## Global Constraints

- Preserve every saved edit permanently; corrections, undo, deletion and replacement append events.
- Resolve each logical field using causal supersession and the canonical maximum (Lamport counter, actor ID, event ID) for independent edits. Preserve differing concurrent edits for optional resolution.
- Save causal parents, deduplicate immutable event IDs, buffer missing dependencies, and converge for permutations and duplicates of the same event set.
- Each installation has a durable logical clock and actor ID; losing counter state creates a new actor ID. Do not use wall clocks or delivery order for conflict decisions.
- Dataset replacement establishes an epoch; old delayed edits cannot affect its successor. Account/day deletion needs explicit generation rules that prevent accidental resurrection.
- Full JSON backups contain the complete versioned log. Legacy JSON and KVS decode into a baseline; no historical edits are invented.
- Preserve user working-tree changes; preserve legacy source/history, iOS identity and React Native availability during transition. Android is retired.
- No signing changes, publishing, CloudKit production schema promotion or App Store replacement without owner approval. Signed real-device sync remains a release gate.

## Review Focus

- Permutations, duplicates, missing dependencies and divergent edits must converge and retain audit history.
- Late edits after deletion/replacement must not resurrect old data.
- Corrupt archives, duplicate IDs with different payloads and interrupted saves must leave existing data intact.
- Decimal historical values, sparse dates, timezone boundaries and legacy Redux compression must survive migration.
- Offline Watch delivery must be idempotent and preserve other fields; saved means persisted, not merely sent.
